# 🌙 月亮饼妙妙屋

一栋可以逛、可以玩、可以请朋友来做客的 3D 小屋。
单个网页文件，电脑和手机都能直接打开，不用安装任何东西。

## 能玩什么

- **逛房子**：三层北欧原木风别墅，有 6 间卧室，后院有泳池，前院有花园。可以拖动旋转看外观，也可以走进屋里逛
- **点一点**：灯、壁炉、窗帘、小猫、钢琴、秋千、滑梯……大部分东西都能点，一共 50 多种互动
- **做饭和吧台**：点单做咖啡、调特调（都有无酒精版）、做菜端上桌、收拾碗筷，还有随季节更换的限定菜单
- **请朋友来**：5 位小动物朋友，可以一起做饭、围桌吃饭、烤火、唱 K
- **开派对**：整栋房子跟着音乐跳舞，还有气球、彩纸和烟花
- **去旅行**：16 个地区（国内 6 个、世界 10 个），每个地方藏着 3 个地标，找齐就能解锁终极彩蛋
- **四季和昼夜**：切换春夏秋冬、白天夜晚，风景、灯光和菜单都会跟着变
- **换颜色**：8 套配色，也可以自己调色
- **记忆卡片**：把当下的画面拍成一张拍立得，可以保存下来

## 怎么打开

**直接玩**：用浏览器打开 `nordic-house.html`。需要联网，因为 3D 引擎 Three.js 要从网上加载。

**放到网上**：任选一种

- **GitHub Pages**：把文件上传到仓库，进入 Settings → Pages 开启，得到一个网址
- **Netlify Drop**：打开 app.netlify.com/drop，把文件拖进去，马上得到一个网址

> 如果仓库里只有这一个页面，可以把文件改名为 `index.html`，这样网址末尾不用再加文件名。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 旋转 / 缩放 | 拖动 / 滚轮 | 单指拖动 / 双指捏合 |
| 走路 | `W A S D` 或方向键，按住 `Shift` 跑 | 左下角方向键 |
| 直达某一层或区域 | `1`～`5`，或底部按钮 | 底部按钮 |
| 开派对 | `P` | 「开派对」按钮 |
| 关闭弹窗 | `Esc` | 点弹窗外面 |

第一次打开会自动弹出使用说明，之后也可以点右上角的「使用说明」再看。

## 存档

进度保存在玩家自己的浏览器里，包括配色、地标进度、收集和回忆相册。

- 更新文件时，只要网址不变，玩家的进度就不会丢
- 清除浏览器数据、使用无痕模式、换浏览器或换设备，进度都会从头开始

## 技术

- [Three.js](https://threejs.org/) r160：3D 渲染
- 原生 HTML / CSS / JavaScript，所有内容都在一个文件里
- 模型、贴图和音乐都是用代码现场生成的，没有用任何外部素材
