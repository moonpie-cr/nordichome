月亮饼妙妙屋 · 使用说明

一栋可以逛、可以玩、可以请朋友来的三层小屋。先看下面 5 条就够了，其它的边玩边发现。

  1. 看房子：拖动画面旋转，滚轮 / 双指缩放。底部 1F / 2F / 3F / 泳池 / 花园 一键直达；进屋后用 WASD 或左下角方向键走路
  2. 点一点：家具、动物、风景大多都能点。电脑上鼠标移上去会提示能做什么，右上角「小幸福」会记录你发现了多少
  3. 请朋友来：点「邀请朋友」，再点「一起玩」：一起做饭、围桌吃饭、烤火、唱 K；点「开派对」整栋房子会跟着音乐跳舞
  4. 去旅行：左侧选地区（16 个），每个地方藏着 3 个「?」地标，找齐就能看到终极彩蛋
  5. 留个纪念：右上角「记忆卡片」把此刻拍成拍立得；底部「换颜色」给小屋换配色

和朋友一起玩、开派对
  • 「邀请朋友」或去前院打开信箱，5 位朋友会来家里玩
  • 「一起玩」：一起做饭（戴小厨师帽）、围桌吃饭、一起烤火（烤棉花糖）、一起唱 K（3F，轮流当主唱，唱完打分）
  • 做菜时朋友会自动来帮忙，菜上桌会自动坐过来吃
  • 「开派对」或键盘 P：音乐、气球、彩纸、烟花、整栋房子跳舞；夜晚效果最好
16 个地区和彩蛋
  • 中国：江南水乡、福建泉州、新疆阿勒泰、四川九寨沟、吉林长白山、海南潜水
  • 世界：北欧峡湾、日本京都、埃及撒哈拉、瑞士雪山、冰岛极光、希腊圣托里尼、加拿大魁北克、巴厘岛、俄罗斯莫斯科、非洲大草原
  • 左侧每个地区后面的 x/3 是地标进度；彩蛋解锁后，连点两次任意地标可以重播
  • 底部还能切换春夏秋冬和白天夜晚，风景、饮品、菜单都会跟着变

操作和小提示
  • 双击画面开关自动旋转；「屋顶」按钮可以隐藏屋顶看布局
  • 键盘 1~5 直达区域，Shift 跑步，Esc 关闭弹窗
  • 换颜色：底部按钮、前院魔法画架，或在外面直接点外墙 / 屋顶；8 套配色或自己调
  • 记忆卡片可以保存成图片，最近 12 张在「回忆相册」里
  • 声音要先点一下页面才会出来；进度保存在当前浏览器里
推荐玩法
  • 邀请朋友 → 夜晚 → 开派对 → 拉远镜头看整栋房子跳舞放烟花
  • 做一桌菜 → 和朋友围桌吃饭 → 收拾碗筷 → 一起烤火
  • 泳池：滑梯滑下去，再跳一次水，躺在躺椅上晒太阳
  • 挨个地区找地标：天池水怪、动物大迁徙、海南潜水……
